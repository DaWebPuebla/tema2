# Introducción

Hemos podido ver como desplegar aplicaciones web en servidores web, utilizando diferentes tecnologías y herramientas. Cubrimos aspectos como la configuración del servidor, la optimización del rendimiento, la seguridad y las mejores prácticas para el despliegue de aplicaciones.

Sin embargo, en entornos de producción, es común utilizar servidores de aplicaciones para gestionar y ejecutar aplicaciones web. Los servidores de aplicaciones proporcionan un entorno más completo y robusto para el despliegue de aplicaciones, ofreciendo características adicionales como la gestión de transacciones, la seguridad avanzada y la integración con bases de datos y otros servicios.

No obstante, el despliegue de aplicaciones web en servidores de aplicaciones puede ser más complejo que en servidores web, ya que requiere una configuración y administración más detallada. Por ello, es importante comprender los fundamentos de los servidores de aplicaciones y aprender a configurarlos y administrarlos correctamente.

Basandonos en lo aprendido en el tema anterior, en este tema nos centraremos en estos servidores de aplicaciones; comentando también como se realizan estas aplicaciones basados en otros lenguajes de programación, como Java, .NET y Python, y cómo se integran con los servidores de aplicaciones para ofrecer una experiencia completa de despliegue de aplicaciones web.

También exploraremos otras prácticas para despliegue como el uso de contenedores y orquestadores, que permiten una mayor flexibilidad y escalabilidad en el despliegue de aplicaciones web. Además, veremos cómo desplegar aplicaciones en entornos de nube, aprovechando las capacidades de estas plataformas para mejorar la disponibilidad y el rendimiento de las aplicaciones web.
