# Servidores de Aplicaciones

En este apartado, exploraremos los conceptos básicos de los servidores de aplicaciones y su importancia en el entorno de despliegue de aplicaciones web.

Los servidores de aplicaciones son componentes fundamentales en el desarrollo y despliegue de aplicaciones web, ya que proporcionan un entorno de ejecución para las aplicaciones, gestionando recursos, seguridad y comunicación entre diferentes partes del sistema.

Vamos en primer lugar, a ver realmente qué es un servidor de aplicaciones y cómo se diferencia de un servidor web. Un servidor de aplicaciones no es más que un software que actúa como intermediario entre el cliente y la aplicación, facilitando la ejecución de la lógica de negocio y la gestión de las solicitudes de los usuarios. 

Cuando nos referimos a un software, nos referimos a un conjunto de programas que se ejecutan en un servidor, y que permiten a los usuarios interactuar con la aplicación web.

Es decir, que un servidor de aplicaciones no es más que un contenedor que ejecuta diferentes aplicaciones web, y que permite a los usuarios interactuar con ellas a través de un navegador web.

## Diferencias entre un servidor web y un servidor de aplicaciones

Podemos encontrar una serie de diferencias entre un servidor web y un servidor de aplicaciones, que nos permiten entender mejor su funcionamiento y su papel en el despliegue de aplicaciones web.

Algunas de estas diferencias son:

* **Funcionalidad**: Un servidor web se centra principalmente en servir contenido estático (refiriendonos a páginas estáticas sin uso de PHP u otro lenguaje del lado servidor), mientras que un servidor de aplicaciones está diseñado para manejar aplicaciones dinámicas y complejas.

* **Gestión de solicitudes**: Un servidor web se encarga de recibir y procesar solicitudes HTTP, mientras que un servidor de aplicaciones se encarga de gestionar la lógica de negocio y la comunicación entre diferentes partes del sistema.

* **Características avanzadas**: Un servidor de aplicaciones puede ofrecer características avanzadas como la gestión de transacciones, la seguridad, la integración con bases de datos y otros servicios, así como la capacidad de escalar y manejar múltiples solicitudes simultáneamente.

* **Lenguajes de programación**: Un servidor web puede soportar diferentes lenguajes de programación, como PHP, Python o Ruby, mientras que un servidor de aplicaciones puede soportar lenguajes más complejos como Java, .NET o Python.

## Aplicaciones basadas en Java, .NET y Python

Aunque dependerá de la naturaleza de cada aplicación, podemos encontrar aplicaciones basadas en diferentes lenguajes de programación, como Java, .NET y Python, que se integran con los servidores de aplicaciones para ofrecer una experiencia completa de despliegue de aplicaciones web.

Estas aplicaciones son diferentes a algunas de las desarrolladas hasta ahora; mientras que las aplicaciones convencionales se basan en una ejecución secuencial de código, las aplicaciones basadas en Java, .NET y Python se basan en un modelo de ejecución más complejo, que permite la ejecución de múltiples hilos de ejecución y la gestión de recursos de manera más eficiente.

Por ejemplo, el punto de entrada de una aplicación basada en Java es la clase principal, que contiene el método `main()` y la interactuación con el usuario se realiza normalmente a través de consola o una interfaz gráfica de usuario (GUI).

Sin embargo, las aplicaciones web basadas en java, se basan en la utilización de un navegador web (u otros clientes web) para interactuar con el usuario, y la ejecución de la lógica de negocio se realiza a través de servlets, JSPs o frameworks como Spring o Struts.

## Servidores de aplicaciones 

Existen diferentes servidores de aplicaciones; nos centraremos actualmente en los servidores de aplicaciones basados en Java.

Algunos de estos servidores de aplicaciones son:

* **Apache Tomcat**: Es un servidor de aplicaciones de código abierto, desarrollado por la Apache Software Foundation, que implementa las especificaciones de Java Servlet y JavaServer Pages (JSP). Es uno de los servidores de aplicaciones más populares y utilizados en el mundo del desarrollo web.

* **JBoss**: Es un servidor de aplicaciones de código abierto, desarrollado por Red Hat, que implementa las especificaciones de Java EE (Enterprise Edition). Es un servidor de aplicaciones robusto y escalable, que ofrece características avanzadas como la gestión de transacciones, la seguridad y la integración con bases de datos y otros servicios.

* **WebLogic**: Es un servidor de aplicaciones desarrollado por Oracle, que implementa las especificaciones de Java EE. Es un servidor de aplicaciones empresarial, que ofrece características avanzadas como la gestión de transacciones, la seguridad y la integración con bases de datos y otros servicios.

* **WebSphere**: Es un servidor de aplicaciones desarrollado por IBM, que implementa las especificaciones de Java EE. Es un servidor de aplicaciones empresarial, que ofrece características avanzadas como la gestión de transacciones, la seguridad y la integración con bases de datos y otros servicios.

* **GlassFish**: Es un servidor de aplicaciones de código abierto, desarrollado por Oracle, que implementa las especificaciones de Java EE. Es un servidor de aplicaciones ligero y fácil de usar, que ofrece características avanzadas como la gestión de transacciones, la seguridad y la integración con bases de datos y otros servicios.
